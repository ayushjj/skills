# Build your own

These are not installable skills. Each file describes a skill I rely on that is too tied to my own
setup to install on yours: what it does, why it is worth having, the steps in plain words, and the
lessons that cost me a bad session each.

To use one: read it, then open a session with your coding agent and paste the prompt at the bottom of
the file, along with the file itself. Your agent inspects your setup and builds a version that fits it.

| Write-up | What you get |
|---|---|
| [session-wrap-and-catchup.md](session-wrap-and-catchup.md) | An end-of-session handover and a start-of-session catch-up, so each session starts where the last one stopped. |
